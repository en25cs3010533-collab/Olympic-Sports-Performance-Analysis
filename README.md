# Global Olympic Sports Performance Analysis

## Overview
A Tableau Public dashboard built from an Olympic medalists CSV dataset.

Charts:
- Top 10 countries by Olympic medal count
- Top sports by athlete-record count

## Dashboard
https://public.tableau.com/app/profile/mahee.silawat/viz/OlympicGameDashboard/Dashboard1

## Project files
- `Olympic Game Dashboard(1).twbx` — Tableau workbook (add your downloaded file)
- `all_olympic_medalists.csv` — source dataset (add your downloaded CSV)
- `Olympic_Sports_Performance_Project_Report.docx` — report

## Tools
- Tableau Public
- CSV
- GitHub for repository and submission

## Method
1. Imported the CSV dataset into Tableau Public.
2. Created a Top 10 country chart using count of medal records.
3. Created a Top 10 sports chart using count of athlete records.
4. Combined both charts in a dashboard and published it.

## Notes
Athlete count is a count of records, not necessarily unique people. Verify dataset details against your exact CSV.
